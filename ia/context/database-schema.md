# Esquema de base de datos

> Pendiente de definir con las sentencias SQL.

## Tablas previstas

- `companies` — Empresas (tenants)
- `users` — Usuarios (pertenecen a una empresa)
- `roles` — Roles del sistema
- `company_services` — Servicios activos por empresa
- `scrum_projects` — Proyectos Scrum
- `scrum_sprints` — Sprints
- `scrum_tasks` — Tareas del tablero
- `tickets` — Incidencias recibidas
- `documents` — Documentos DPD/ISO
- `document_permissions` — Permisos por documento
- `fichajes` — Registros de login
- `audit_logs` — Registro de actividad
