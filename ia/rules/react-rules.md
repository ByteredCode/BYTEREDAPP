# Reglas Frontend (React + Vite + JS)

- JavaScript plano (NO TypeScript)
- CSS plano en `src/styles/` (NO Tailwind, NO styled-components)
- Nombres de componentes en PascalCase: `UserTable.jsx`
- Nombres de hooks con prefijo `use`: `useAuth.js`
- Usar `pnpm` para instalar dependencias
- Llamadas API centralizadas en `src/services/`
- Estado global con React Context (en `src/context/`)
- Cada página en su carpeta dentro de `src/pages/`
- Componentes reutilizables en `src/components/common/`
